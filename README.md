Project Name 
My Python Mini Toolkit is a beginner-friendly Python application created by Ishma-iel Gray.
The Project combines multiple useful mini tools into one program to solve everyday problems in a simple and interactive way.
It includes a Grade Calculator, To-Do-List and Daily Motivation Generator, and a Main Menu for navigation.

Features of Project:
Grade Calculator: Calculates average marks and displays grades.
To-D0-List: Allows users to add and view tasks.
Daily Motivation Generator: Displays random motivational quotes.
Menu System: Lets users easily move between tools.

Python Concepts Used:
Variables and Data Types
User Input and Output
Type Casting
Arithmetic Operators
Comparison and Logical Operators
if, elif, and else Statements
Loops(for and while)
Lists and Dictionaries
Functions and Modules

How to Run the Project:
Install Python on your computer
Save the project as helpers.py.
Open the terminal or command prompt
Navigate to the project folder
Run program using VS Code
